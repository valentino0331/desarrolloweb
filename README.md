## 🚀 Inicio Rápido
Para levantar el servidor backend de Spring Boot:
1. Ejecuta el archivo de inicio rápido:
   ```cmd
   iniciar_proyecto.bat
   ```
2. La API estará disponible en `http://localhost:8080/`.
3. Consola H2 en `http://localhost:8080/h2-console` (JDBC URL: `jdbc:h2:mem:ecotechtrackdb`, User: `sa`, Password: vacía).
