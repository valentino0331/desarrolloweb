@Entity @Table(name = "residuos_electronicos") public class ResiduoElectronico { @Id @GeneratedValue(strategy = IDENTITY) private Long id; @Column(unique = true, nullable = false) private String codigoIdentificacion; private Double pesoKg; @Enumerated(EnumType.STRING) private CategoriaRAEE categoria; @Enumerated(EnumType.STRING) private EstadoResiduo estado; @PrePersist public void prePersist() { this.fechaRegistro = LocalDateTime.now(); if(this.estado == null) this.estado = EstadoResiduo.DECLARADO_BAJA; } }

  • 4. EN_TRANSITO Transporte hacia la planta autorizada.
  • 5. EN_PLANTA_VALORIZACION Desensamblaje y recuperación.

Capa Web y Seguridad de Entrada • Integrante 2

Patrón DTO y Validación Declarativa

Desacoplamiento arquitectónico y validación con Jakarta Bean Validation

🛡️ ¿Por qué usamos el Patrón DTO?
  • Seguridad: Previene vulnerabilidades de asignación masiva (Mass Assignment) impidiendo modificar IDs o fechas arbitrariamente.
  • Desacoplamiento: Los cambios en la tabla relacional no rompen los contratos JSON consumidos por los clientes (Angular/Mobile).
  • DTOs Diseñados: ResiduoRequestDTO, ResiduoResponseDTO y CambioEstadoDTO.
✅ Validaciones en ResiduoRequestDTO
public class ResiduoRequestDTO { @NotBlank(message = "El código es obligatorio") private String codigoIdentificacion; @NotBlank(message = "La descripción no puede estar vacía") private String descripcion; @NotNull(message = "El peso es requerido") @Positive(message = "El peso en Kg debe ser mayor a 0") private Double pesoKg; @NotNull(message = "Debe clasificar la categoría RAEE") private CategoriaRAEE categoria; }

Control de Excepciones • Integrante 2

Manejo Global con @RestControllerAdvice

Centralización de fallos sin bloques try-catch dispersos

⚠️ Intercepción de Excepciones
  • ResourceNotFoundException: Mapeado automáticamente a HTTP 404 Not Found.
  • BadRequestException: Mapeado a HTTP 400 Bad Request.
  • MethodArgumentNotValidException: Captura fallos de Bean Validation y compila los campos erróneos en una lista legible.
  • HttpMessageNotReadableException: Captura JSON malformados o valores de enum inválidos (HTTP 400).

Aseguramiento de Calidad • Integrante 3

Pruebas Unitarias Web con TDD y MockMvc

Validación automatizada de controladores con JUnit 5, Mockito y MockMvc

🧪 Enfoque TDD (Semana 3)

Diseño de las especificaciones de los endpoints y los códigos de respuesta esperados antes de la integración final, garantizando cobertura de casos positivos y negativos.

⚡ @WebMvcTest Ligero

Prueba exclusivamente la capa web (controlador y mapeo JSON). No levanta la base de datos real ni servidores externos, ejecutando los tests en milisegundos.

🎭 Aislamiento con @MockBean

Simula las respuestas de ResiduoService con Mockito (when(...).thenReturn(...)), aislando la prueba de cualquier fallo colateral.
